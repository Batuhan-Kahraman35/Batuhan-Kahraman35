# Merhaba, ben Batuhan 👋

Kurumsal yönetim panelleri, CRM, destek sistemleri ve iş süreçleri otomasyonu geliştiren **full-stack yazılım geliştiricisiyim**.
Backend'de PHP + MSSQL, API tarafında Node.js/TypeScript, istemci tarafında React PWA ve React Native ile çalışıyorum.

- 🔭 Şu an: Kurumsal yönetim panelleri, destek (ticket), CRM ve uzak yönetim (RMM) sistemleri
- ⚙️ Odak: Server-side DataTables, MSSQL sorgu optimizasyonu, REST API, n8n ile otomasyon
- 📱 Mobil: Personel devam kontrol (PDKS) için React PWA ve Expo / React Native uygulaması
- 🖥️ Ajan: Windows makineleri yöneten PowerShell tabanlı RMM ajanı
- 🐳 Altyapı: Docker, Windows Server, IIS, Plesk
- 📫 İletişim: [LinkedIn](https://www.linkedin.com/in/batuhan-kahraman-39725b2a2/)
